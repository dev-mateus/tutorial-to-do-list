# Tutorial Passo 11 - Rodar e validar o projeto

## Objetivo do passo
Executar a aplicacao e validar se tudo funciona em desenvolvimento e producao.

## O que sera aprendido
- Por que testar em mais de um modo e importante.
- Como usar os comandos principais do fluxo front-end.

## Codigo necessario
### Comandos
```bash
npm run dev
npm run build
npm run preview
```

## Explicacao linha a linha
- npm run dev inicia servidor de desenvolvimento com atualizacao em tempo real.
- npm run build faz checagem de tipos e gera arquivos otimizados em dist.
- npm run preview abre localmente a versao de producao para teste final.

## O que o aluno construiu
Um fluxo completo de validacao: desenvolvimento, build e verificacao final da aplicacao.
